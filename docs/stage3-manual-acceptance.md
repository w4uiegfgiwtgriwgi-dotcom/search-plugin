# 阶段3手动验收说明

> 目标：验证 Chrome MV3 扩展能在用户主动点击后，把当前公开页面保存到本地素材库。

## 前置条件

- 已安装并能运行桌面端或本地 API。
- 本地 API 地址可访问：`http://127.0.0.1:17860`。
- Chrome 浏览器允许加载未打包扩展。

## 自动冒烟检查

先启动桌面端，或手动启动本地 API，然后运行：

```powershell
cd E:\搜索插件\apps\local-api
& '..\..\.venv\Scripts\python.exe' scripts\stage3_browser_collect_smoke.py
```

如果 `17860` 端口已经被旧服务占用，可以先用其他端口启动本地 API，并指定 `VMF_API_BASE`：

```powershell
$env:VMF_API_BASE='http://127.0.0.1:17861'
& '..\..\.venv\Scripts\python.exe' scripts\stage3_browser_collect_smoke.py
```

通过时会看到：

```json
{
  "passed": true,
  "source": "浏览器采集",
  "site_name": "Example"
}
```

## Chrome 扩展加载

1. 打开 Chrome。
2. 访问 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择目录：`E:\搜索插件\apps\browser-extension`。

## 人工验收步骤

1. 启动桌面端，确认 API 状态为 ready。
2. 在桌面端创建或选择一个项目。
3. 在 Chrome 打开一个公开网页，例如 `https://example.com/`。
4. 点击浏览器扩展“全网视频素材智能搜索助手”。
5. 在扩展弹窗里点击“刷新项目”。
6. 选择目标项目。
7. 点击“保存当前公开页面”。
8. 回到桌面端项目素材区，点击“刷新素材”。
9. 确认素材列表中出现该网页，并显示“浏览器采集”。

## 通过标准

- 扩展弹窗能显示本地项目列表。
- 保存后扩展提示“已保存到项目”。
- 桌面端素材库出现对应页面标题和链接。
- 素材来源显示为“浏览器采集”。
- 素材卡片能显示站点、作者或发布时间中的可用字段。

## 不通过时检查

- 如果扩展提示本地 API 不可用，先启动桌面端或本地 API。
- 如果项目列表为空，确认桌面端已创建项目，或直接使用自动创建项目。
- 如果保存成功但桌面端看不到，点击“刷新素材”，并确认当前选择的是同一个项目。
- 如果 Chrome 不允许加载扩展，确认已经打开开发者模式。
