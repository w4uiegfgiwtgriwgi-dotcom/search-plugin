## 已完成

- Chrome MV3 扩展可在用户主动点击后读取当前公开页面信息。
- 扩展支持读取标题、URL、作者、描述、封面、发布时间、站点名和主机名。
- 扩展弹窗可读取本地项目列表，并把当前页面保存到用户选中的项目。
- 扩展提供“刷新项目”按钮，请求期间会禁用按钮，避免重复保存或重复刷新。
- 本地 API 提供浏览器采集入口，并把页面写入搜索结果和项目素材库。
- 桌面端项目素材区提供“浏览器扩展采集”提示、“只看浏览器采集”和“刷新素材”入口。
- 项目素材关键词搜索已覆盖采集来源、站点、主机名、作者和发布时间字段。
- 新增阶段3一键检查脚本：`npm run stage3:check`。

## 人工验收建议

阶段3自动检查已经通过，但浏览器扩展仍建议做一次真实 Chrome 人工验收：

1. 启动桌面端，确认 API 状态为 ready。
2. 打开 `chrome://extensions/`，加载 `E:\搜索插件\apps\browser-extension`。
3. 打开一个公开网页，例如 `https://example.com/`。
4. 点击扩展，刷新项目列表，选择目标项目。
5. 点击“保存当前公开页面”。
6. 回到桌面端项目素材区，点击“刷新素材”。
7. 确认素材出现，并显示来源“浏览器采集”。

详细步骤见 `docs/stage3-manual-acceptance.md`。

## 已知风险

- 当前浏览器采集主要依赖公开 meta 字段，不同平台页面结构差异较大，字段完整度会波动。
- 当前 OCR 和视觉向量仍是 Mock Provider，不能代表真实识别效果。
- 当前扩展以用户主动点击为边界，不适合做自动批量采集。
- 后续打包 Electron 时仍需继续审查 FFmpeg、Electron 和第三方依赖许可证边界。
