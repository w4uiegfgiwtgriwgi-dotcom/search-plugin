# 阶段5安全审查与许可证复核

> 日期：2026-08-12  
> 范围：生产化前安全边界、依赖许可证、FFmpeg 分发策略、用户数据和平台合规。  
> 结论：当前可以继续作为本地 MVP 推进；生成正式安装包前仍需做一次依赖清单复核。

## 安全边界复核

当前项目坚持以下边界：

- 不保存密码、完整 Cookie、Token 或登录态。
- 不实现验证码绕过、DRM 破解、代理证书拦截或加密视频解密。
- 不自动发布、评论、点赞、关注或私信。
- 不使用真实账号进行无人值守高频测试。
- 不自动批量翻页、批量抓取或规避平台访问限制。
- 视频号能力仅为搜索词生成、人工步骤提示和用户手动公开链接保存。
- 浏览器扩展只在用户主动点击后读取当前公开页面信息。

## 用户数据复核

- 本地数据位于 `.local-data`，已被 `.gitignore` 忽略。
- 本地备份位于 `backups/`，已被 `.gitignore` 忽略。
- 备份 zip 可能包含用户素材路径、截图、缩略图和项目备注，不应公开分享。
- 恢复数据前建议关闭桌面端和本地 API，避免覆盖正在写入的数据库。

## 许可证复核

当前代码仓库没有提交第三方二进制文件，也没有复制第三方仓库代码。

当前主要运行依赖：

| 依赖 | 用途 | 当前判断 |
|---|---|---|
| Electron | Windows 桌面壳 | MIT，当前可接受 |
| React / React DOM | UI 基础 | MIT，当前可接受 |
| Vite / @vitejs/plugin-react | 前端构建辅助 | MIT，当前可接受 |
| FastAPI / Starlette / Uvicorn | 本地 API | 常见宽松许可证，继续保留锁定文件 |
| SQLite | 本地数据库 | 随 Python 标准库使用 |
| FFmpeg | 视频抽帧和探测 | 当前作为外部系统依赖，不随仓库或安装包分发 |

## FFmpeg 结论

当前本机 FFmpeg 来自 gyan.dev `essentials_build`，检测到版本为 `9.0-essentials_build`。该构建可能包含 GPL/version3 选项。

阶段5当前策略：

- 不把 FFmpeg 二进制文件提交到仓库。
- 不把 FFmpeg 二进制文件直接打进第一版安装包。
- 通过运行环境检查提示用户自行安装 FFmpeg 并加入 PATH。
- 如果未来决定随包分发，必须重新审查 GPL/LGPL 构建、源码提供义务和许可证声明。

## 打包前剩余风险

- 尚未生成第三方依赖许可证清单。
- 尚未接入安装包签名。
- 尚未设计自动更新和回滚策略。
- 尚未提供真实 OCR/视觉模型，因此不能宣传真实识别准确率。
- 尚未进行低配 Windows 机器性能测试。

## 生产化结论

当前可以继续进入 Windows 打包配置和用户说明阶段。  
在正式发布安装包前，必须再次确认：

1. 安装包是否包含 FFmpeg。
2. 安装包是否包含 Python 虚拟环境或改为系统依赖。
3. 依赖许可证清单是否随安装包提供。
4. 用户数据备份和恢复说明是否包含在最终用户文档中。
