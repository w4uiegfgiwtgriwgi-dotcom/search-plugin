# 用户使用说明

> 适用范围：当前 Windows 本地 MVP。  
> 当前版本仍使用 Mock OCR 和 Mock 视觉向量，不宣称真实全网自动搜索能力。

## 先准备

1. 确认已经安装 Node、Python 虚拟环境依赖和 FFmpeg。
2. 确认 FFmpeg 已加入系统 PATH。
3. 在项目根目录运行一次环境检查：

```powershell
cd E:\搜索插件
npm run stage5:runtime-check
```

看到 `Stage5 runtime check passed.` 就可以继续。

## 启动桌面端

```powershell
cd E:\搜索插件\apps\desktop
npm start
```

桌面端启动后会自动检查本地 API：

- 显示“API 已连接”：说明已有本地 API 正在运行。
- 显示“API 已自动启动”：说明桌面端帮你拉起了本地 API。
- 显示“API 启动失败”：先检查 Python 虚拟环境和 `17860` 端口。

## 创建项目

1. 在“项目”区域输入项目名。
2. 点击“创建”。
3. 后续搜索收藏、截图反查结果、浏览器采集和视频号手动链接都会进入当前项目素材库。

## 关键词搜索

1. 在顶部输入画面描述、关键词、台词或 URL。
2. 选择平台，例如“公开网页”“B站样本”。
3. 点击“开始搜索”。
4. 看到结果后，点击“收藏到项目”。
5. 在“项目素材”区点击“刷新素材”查看收藏结果。

## 项目素材库

素材库可以做这些事：

- 按关键词、类型、复核状态、版权状态、可信度筛选。
- 修改复核状态：待复核、已确认、已拒绝。
- 修改版权状态：未知、可用、需授权、不可用。
- 编辑标签和备注。
- 导出 CSV、JSON 或 Markdown。

建议：

- 没有确认版权前，不要把素材标为“可用”。
- 截图反查低可信素材要先人工回看时间点。
- 浏览器采集和视频号手动链接默认都需要人工复核。

## 截图反查

可以通过三种方式提供截图：

- 填写截图路径。
- 点击“上传截图”选择图片。
- 把截图拖进“拖拽截图”区域，或直接粘贴剪贴板截图。

基本流程：

1. 先分析截图。
2. 填写候选视频路径。
3. 点击“匹配候选视频”。
4. 如果找到疑似画面，查看时间点、匹配分和证据。
5. 点击“收藏当前匹配帧”或“收藏高分匹配”。

注意：

- 当前 OCR 和视觉向量仍是 Mock Provider。
- pHash、抽帧、时间点和本地视频匹配是真实执行。
- 低分结果不能直接当成命中，需要人工确认。

## 浏览器扩展采集

加载扩展：

1. 打开 Chrome。
2. 访问 `chrome://extensions/`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择目录：`E:\搜索插件\apps\browser-extension`。

采集公开页面：

1. 先启动桌面端。
2. 在 Chrome 打开一个公开网页。
3. 点击扩展“全网视频素材智能搜索助手”。
4. 点击“刷新项目”，选择目标项目。
5. 点击“保存当前公开页面”。
6. 回到桌面端项目素材区，点击“刷新素材”。

扩展只在你主动点击后读取当前公开页面信息，不读取密码、Cookie、Token 或登录态。

## 视频号半自动

视频号当前只支持半自动流程。

生成搜索计划：

1. 在“视频号半自动”面板输入画面线索。
2. 填写补充关键词。
3. 点击“生成搜索计划”。
4. 复制“微信内搜索”或“网页辅助搜索”的搜索词。
5. 用户自己在微信或浏览器中搜索。

保存手动链接：

1. 找到公开链接后，复制链接。
2. 粘贴到“手动复制的公开链接”。
3. 填写素材标题。
4. 点击“保存到当前项目”。
5. 回到项目素材区确认素材出现。

视频号半自动不会：

- 自动登录微信。
- 自动搜索或翻页。
- 读取微信登录态。
- 绕过验证码。
- 自动点赞、评论、关注、私信或发布。

## 备份和恢复

备份本地素材库：

```powershell
cd E:\搜索插件
npm run stage5:backup-data
```

备份会生成在：

```text
E:\搜索插件\backups
```

恢复备份：

```powershell
cd E:\搜索插件
npm run stage5:restore-data -- "E:\搜索插件\backups\你的备份文件.zip"
```

恢复前建议关闭桌面端和本地 API。恢复脚本会先自动备份当前数据，再覆盖 `.local-data`。

## 常见问题

### API 启动失败

先运行：

```powershell
cd E:\搜索插件
npm run stage5:runtime-check
```

重点看 Python、FFmpeg 和端口 `17860`。

### FFmpeg 找不到

确认命令行能运行：

```powershell
ffmpeg -version
```

如果不能运行，需要安装 FFmpeg 并加入 PATH。

### 浏览器扩展保存后桌面端看不到

1. 确认桌面端正在运行。
2. 确认扩展选择的是同一个项目。
3. 点击“刷新素材”。
4. 搜索关键词“浏览器采集”。

### GitHub 推送失败

这不影响本地使用。项目代码和本地数据仍在本机。网络恢复后再推送即可。

## 重要边界

- 不保存密码、完整 Cookie、Token 或登录态。
- 不绕过验证码、DRM、代理证书或平台限制。
- 不自动发布、评论、点赞、关注或私信。
- 不承诺覆盖互联网全部内容。
- 所有素材进入交付前，都需要人工复核来源和版权。
