# 浏览器扩展阶段3入口

当前扩展只在用户主动点击按钮后读取当前可见页面的公开信息，不读取密码、不导出 Cookie、不后台高频访问。

已支持：

- 读取当前标签页的标题、URL、作者 meta、描述 meta、封面 meta、发布时间 meta 和站点名。
- 从本地 API 读取项目列表，保存前可选择目标项目。
- 可手动刷新项目列表，避免桌面端新建项目后扩展弹窗里看不到。
- 调用本地 API：`POST http://127.0.0.1:17860/api/browser/collect-page`。
- 本地 API 会自动创建或复用“浏览器采集素材”项目，并把页面保存为项目素材。

使用前需要先启动桌面端或本地 API，确保 `127.0.0.1:17860` 可访问。
