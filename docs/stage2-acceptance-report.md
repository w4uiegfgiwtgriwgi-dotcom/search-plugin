## 验收结论

阶段2 Mock Provider 验收通过。

当前已经形成本地截图反查闭环：截图分析、文件上传、拖拽/粘贴、多图批量上传、候选视频抽帧、粗扫加精排匹配、批量候选匹配、批量截图匹配、高分匹配收藏、统一项目素材库、复核状态、版权状态、标签备注、筛选排序、时间线、待处理清单、可用状态和 CSV/JSON/Markdown 导出。

## 已完成

- 本地 API 支持截图路径分析和截图文件上传。
- 上传截图会保存到本地 `.local-data`，并做文件名净化、格式校验、空文件校验和大小限制。
- 支持单图、批量截图、拖拽截图和剪贴板粘贴截图。
- 支持候选视频 FFmpeg 抽帧、pHash 打分、Mock 视觉向量打分和 Mock OCR 文本打分。
- 支持先粗扫再局部精排，并输出匹配时间点、结束时间点、片段时长和证据摘要。
- 支持批量候选视频匹配，单个候选失败不会影响其他候选。
- 支持多张截图批量匹配同一批候选视频。
- 支持把当前匹配帧或高分匹配批量收藏到项目。
- 统一项目素材库已合并阶段1搜索收藏和阶段2截图反查收藏。
- 素材库支持来源、复核状态、版权状态、匹配可信度、待处理类型、关键词和排序筛选。
- 素材卡片支持标签、备注、复核状态和版权状态编辑。
- 素材库新增时间码、片段时长、匹配证据摘要、可信度标签、待处理建议和可用状态。
- 导出支持 CSV、JSON、Markdown，并包含导出概览、待处理清单和截图反查时间线。
- 桌面端 Electron 可自动拉起或连接本地 API，阶段2界面可操作截图反查主流程。

## 未完成

- OCR 仍是 Mock Provider，不能识别真实截图文字。
- 视觉向量仍是 Mock Provider，不能代表真实 CLIP/embedding 效果。
- ASR 尚未接入，暂不支持从用户上传短视频提取语音字幕。
- 真实平台搜索和浏览器登录采集尚未接入。
- 浏览器扩展还没有把当前页面采集结果写入本地 API。
- Electron 尚未打包成 Windows 安装包。
- 素材删除功能尚未开放；删除属于破坏性操作，需要单独授权。

## 已知风险

- Mock Provider 只能证明接口和流程正确，不能证明真实识别效果。
- pHash 对裁剪、遮挡、二次拍屏、强滤镜、平台 UI 遮挡的鲁棒性有限。
- 当前阈值、权重和精排窗口是阶段2临时基线，接真实模型后需要重新标定。
- 当前候选视频主要依赖用户本地提供路径，还没有真实平台候选采集能力。
- FFmpeg 相关分发仍需保持许可证审查，避免后续打包时踩 GPL/LGPL 边界。

## 下一阶段建议

阶段2可以关门。建议进入阶段3：浏览器扩展与本地 API 打通。

阶段3优先顺序：

1. 让 Chrome MV3 扩展读取用户当前可见页面标题、链接、作者等公开信息。
2. 扩展把用户主动采集的页面信息发送到 `127.0.0.1:17860` 本地 API。
3. 本地 API 新增浏览器采集入口，把页面结果保存为项目素材或搜索候选。
4. 桌面端显示“来自浏览器扩展”的素材来源和采集时间。
5. 补扩展到本地 API 的集成测试和手动验收说明。
