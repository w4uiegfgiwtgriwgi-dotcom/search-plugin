# 阶段4手动验收说明

> 目标：验证视频号半自动流程能从线索生成搜索计划，并把用户手动找到的公开链接保存到当前项目素材库。  
> 边界：不登录微信、不读取密码、Cookie、Token 或登录态；不自动搜索、不自动翻页、不批量抓取、不绕过验证码。

## 前置条件

- 桌面端可以正常启动。
- 本地 API 状态显示为 ready。
- 已创建或选择一个项目。
- 用户自己可以打开微信或浏览器进行人工搜索。

## 自动检查

```powershell
cd E:\搜索插件
npm run stage4:check
```

通过时会看到：

```text
Stage4 checks passed.
```

## 人工验收步骤

1. 启动桌面端。
2. 在“视频号半自动”面板输入画面线索，例如：`极端高温废墟里男人翻垃圾，最后发现旧空调`。
3. 在“补充关键词”里输入：`男人翻垃圾，旧空调`。
4. 点击“生成搜索计划”。
5. 确认面板出现“微信内搜索”“网页辅助搜索”“候选搜索词”“人工搜索”“采集回素材库”和“安全边界”。
6. 点击任意搜索词或复制按钮，确认状态栏提示已复制。
7. 用户自行在微信或浏览器中搜索公开内容。
8. 把人工找到的公开视频号网页链接或相关网页链接粘贴到“手动复制的公开链接”。
9. 填写“素材标题”，点击“保存到当前项目”。
10. 回到“项目素材”区域，确认素材列表出现该链接。
11. 确认素材来源为用户主动采集，版权状态仍需要人工复核。

## 通过标准

- 能生成视频号搜索计划。
- 搜索词复制按钮可用。
- 手动公开链接可以保存到当前项目素材库。
- 保存后素材库会刷新。
- 界面清楚提示安全边界，不宣称自动搜索或真实平台抓取。

## 不通过时检查

- 如果提示本地 API 不可用，先确认桌面端 API 状态为 ready。
- 如果保存链接失败，确认链接以 `http://` 或 `https://` 开头。
- 如果素材库看不到新素材，确认当前项目没有切换，并点击“刷新素材”。
- 如果复制失败，可以手动选中搜索词复制；这不影响主流程验收。
