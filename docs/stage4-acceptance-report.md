## 人工验收建议

阶段4自动检查已通过，建议再做一次桌面端人工验收：

1. 启动桌面端，确认 API 状态为 ready。
2. 在“视频号半自动”面板输入画面线索和补充关键词。
3. 点击“生成搜索计划”，确认搜索词、人工步骤和安全边界可见。
4. 点击复制按钮，确认状态栏提示已复制。
5. 用户自行在微信或浏览器搜索公开内容。
6. 把手动找到的公开链接粘贴到“手动复制的公开链接”。
7. 填写素材标题，点击“保存到当前项目”。
8. 在项目素材区确认素材出现，并保持版权状态待复核。

详细步骤见 `docs/stage4-manual-acceptance.md`。

## 已知风险

- 视频号开放能力有限，当前只能提供半自动人工搜索和用户主动采集流程。
- 用户手动复制的链接可能不是公开视频页，保存时只做基础 URL 校验。
- 视频号页面字段不稳定，真实标题、作者、发布时间等仍需要用户人工复核。
- 当前 OCR 和视觉向量仍是 Mock Provider，不能代表真实模型识别效果。
- 版权状态默认未知，任何素材进入交付前都需要人工确认授权。
