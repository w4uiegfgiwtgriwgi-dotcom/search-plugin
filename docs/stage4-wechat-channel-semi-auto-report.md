# 阶段4视频号半自动流程报告

> 日期：2026-08-12  
> 范围：阶段4第一小步，先提供视频号搜索词生成和人工搜索指引。  
> 边界：不登录微信、不读取登录态、不自动搜索、不批量抓取、不绕过验证码，不做代理证书、解密或拦截方案。

## 已完成

- 新增本地 API：`POST /api/wechat-channel/search-plan`。
- 输入画面描述、关键词、台词或视频线索后，生成适合视频号人工搜索的候选搜索词。
- 输出可复制的搜索词块，分为微信内搜索和网页辅助搜索两类。
- 输出人工搜索步骤，指导用户自行打开微信、搜索、判断疑似素材。
- 输出采集步骤，指导用户用浏览器扩展或手动复制公开链接，把候选内容带回本地素材库。
- 输出安全边界，明确不读取密码、Cookie、Token 或登录态，不自动翻页、不绕过验证码、不自动互动。
- 新增服务层测试，覆盖搜索词生成、半自动模式和安全边界。

## 本次补充：桌面端入口

- 桌面端新增“视频号半自动”面板。
- 面板支持输入视频号线索和补充关键词，调用本地 API 生成搜索计划。
- 面板展示微信内搜索词、网页辅助搜索词、候选搜索词、人工搜索步骤、采集步骤和安全边界。
- 搜索词支持一键复制，方便用户在微信或浏览器中手动搜索。
- 这一步仍不自动打开微信、不自动搜索、不读取或保存登录态。

## 本次补充：手动链接保存

- 桌面端视频号半自动面板新增“手动复制的公开链接”和“素材标题”输入框。
- 用户可以把自己人工找到的公开视频号网页链接或相关网页链接保存到当前项目素材库。
- 保存逻辑复用浏览器采集入口，来源仍是用户主动采集，版权状态默认未知。
- 链接保存后会刷新当前项目素材库，方便继续做复核、标注和截图反查。
- 这一步只接受用户手动提供的公开链接，不读取微信登录态，不自动抓取微信客户端内容。

## 示例请求

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:17860/api/wechat-channel/search-plan -ContentType 'application/json' -Body '{"query":"极端高温废墟里男人翻垃圾，最后发现旧空调","keywords":["男人翻垃圾","旧空调"]}'
```

## 当前限制

- 还没有读取真实视频号页面结构，也不保存微信登录态。
- 当前不会自动打开微信、自动搜索、自动翻页或批量采集。
- 与截图的匹配仍依赖用户主动提供截图、公开页面或本地候选视频。

2. 做一次真实桌面端人工验收，记录搜索词生成、复制和手动链接保存结果。
